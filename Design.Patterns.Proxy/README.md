# Proxy Pattern

### Core Types

1. Remote Proxy
2. Virtual Proxy
3. Protection Proxy

| Remote Proxy                                        | Virtual Proxy                                                  | Protection Proxy                       |
|-----------------------------------------------------|----------------------------------------------------------------|----------------------------------------|
| Provides a local representation for a remote object | Creates a placeholder for expensive objects, e.g: Lazy loading | Controls access to the original object |


### Other Types

1. Smart Reference Proxy
2. Caching Proxy

| Smart Reference Proxy                                 | Caching Proxy                             |
|-------------------------------------------------------|-------------------------------------------|
| Acts as an intelligent wrapper around the real object | Stores the result of expensive operations |
